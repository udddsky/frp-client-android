# FRP Android Client

这是一个最小可运行骨架，提供一个安卓界面用于配置 FRP 服务端参数，并通过前台服务尝试启动 `frpc`。

## 关键说明

- 真实的 FRP 功能依赖一个 Android 可执行的 `frpc` 二进制。
- 现在项目已支持“按版本切换”二进制：启动时会优先查找 `assets/frpc-<版本>`，例如 `app/src/main/assets/frpc-0.52.3`。
- 如果没有对应版本文件，则回退到 `app/src/main/assets/frpc`。
- 你也可以把已下载的二进制手动复制到应用私有目录 `files/bin/frpc-<版本>` 或 `files/bin/frpc`。

## 运行方式

1. 打开 Android Studio，导入这个目录。
2. 在 `app/src/main/assets/` 下放入 FRP 二进制文件：
   - 例如 `frpc-0.52.3` 表示版本 `0.52.3`
   - 或者直接放 `frpc` 作为默认回退文件
3. 在应用界面里输入对应的版本名（例如 `0.52.3`），然后启动。
4. 运行到设备/模拟器。

## 预计支持

- 输入 FRP 服务端地址、端口、Token
- 输入本地 IP / 本地端口 / 远端端口
- 选择并切换不同版本的 FRP 二进制
- 启动/停止 FRP 代理

## 说明

本项目属于“可编译骨架”，不是一个已经包含官方 frp 客户端能力的完整封装。
